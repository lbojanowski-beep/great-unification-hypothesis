## Epistemic status (read first)

This proxy was locked because it is the only weak-field biology path with a real mechanistic literature. That makes it valuable **scaffolding** (named carrier, named amplifier, writeable lab signatures). It does **not** by itself make GUH scientific, and it does **not** currently test any claim that is *unique to GUH*.

Discipline for Option A comes from the **energy-budget filter** (interaction vs \(kT\), named amplifier, falsifiable signature) — not from choosing RP. Adopting RP makes GUH **adjacent to** something scientific; it does not convert GUH’s own content into a risky prediction.

Standard RP falsifiers (orientation dependence, Earth-strength window, RF cutoff, hyperfine mutants) falsify **RP in a given system**. If they all pass, GUH gains nothing (RP was already known to work in the cited systems). If they all fail, GUH loses nothing (no GUH-specific content was in the test). That is the definition of a **non-bearing test** for GUH.

## Gate before any toy Hamiltonian

**Do not** compute \(\Phi_S(B,\theta)\) at \(50\,\mu\mathrm{T}\) as a “GUH result” until a **predicted deviation from standard RP** is pre-registered in writing:

- What quantitative departure from the textbook RP compass / CRY4 / RF-cutoff package does GUH predict?
- What result would count as **GUH lose** (not “RP fail” and not “RP succeed”)?

Without that, every agreement with RP literature looks like GUH success and every difference looks like GUH signal — a test that cannot lose.
